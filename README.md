# 💍 Rupesh & Laxmi - Wedding Invitation Website

A premium, interactive digital wedding invitation with animated envelope, countdown timer, event timeline, and Google Maps integration.

## 📁 Project Structure

```
rupesh-laxmi-wedding/
├── index.html          # Main HTML page
├── style.css           # All styling (gold/cream/maroon theme)
├── script.js           # Envelope animation, countdown, music, scroll reveal
├── assets/
│   ├── audio/
│   │   └── music.mp3   # ← Place your background music here
│   └── images/
│       └── ...         # ← Place couple photos here (for gallery)
└── README.md
```

## 🚀 How to View

1. Open `index.html` in any modern browser
2. Tap the envelope to open the invitation
3. Background music will play automatically (if music.mp3 is provided)

## 🎵 Adding Background Music

Place your MP3 file at:
```
assets/audio/music.mp3
```
A classic shehnai or romantic instrumental track works best.

## 📸 Adding Photos

When you have pre-wedding or engagement photos ready, place them in `assets/images/` and update the gallery section in `index.html` — replace the placeholder `<div class="gallery-placeholder">` blocks with `<img>` tags.

## 🌐 Deployment

This is a static website. Deploy it on any hosting platform:
- **Netlify** (drag & drop the folder)
- **Vercel**
- **GitHub Pages**
- **Any web hosting with FTP**
